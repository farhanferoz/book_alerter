# book_alerter web

Vite + React + TypeScript frontend for Book Alerter.

```
npm install
npm run dev      # dev server with /api proxy to FastAPI on :8000
npm run build    # tsc -b && vite build
npm run lint     # eslint .
```

See `docs/superpowers/plans/2026-05-09-book-alerter-implementation.md` for phase context.
